## Load

1. Open `chrome://extensions`
2. Enable Developer mode
3. Load unpacked → this directory
4. Open [chatgpt.com](https://chatgpt.com)

---

## Shortcuts

| Key     | Action         |
| ------- | -------------- |
| `Alt+N` | New chat       |
| `Alt+L` | Toggle sidebar |
| `Alt+I` | Temporary chat |
